# Permissions

NoShitMac requires three macOS privacy permissions.

## Accessibility

**Used for:** Activating windows across Spaces and fullscreen apps.

**Grant:** System Settings → Privacy & Security → Accessibility → enable **NoShitMac**

Or click **Grant** in the menu bar dropdown.

## Screen Recording

**Used for:** Screenshots and window thumbnails in the switcher overlay.

**Grant:** System Settings → Privacy & Security → Screen Recording → enable **NoShitMac**

## Input Monitoring

**Used for:** Global hotkeys via `CGEventTap` (`⌥ Tab`, `⌥⇧ 4`).

**Grant:** System Settings → Privacy & Security → Input Monitoring → enable **NoShitMac**

## After Granting

Quit and relaunch NoShitMac, or click the menu bar icon to refresh permission status.

## Deep Links

The app opens the correct Settings pane when you click **Grant** in the menu.
